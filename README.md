# Presentabot

Presentabot is a planned local presentation authoring application for people and agents. It combines Slidev presentations, reusable components, organization resources, image generation, and project cost tracking.

## Project Status

This repository contains the proposed product contract and Stokker project bootstrap. The application and CLI are not implemented or published yet.

The [foundation proposal](openspec/changes/presentabot-foundation/proposal.md) defines scope, and the [design](openspec/changes/presentabot-foundation/design.md) defines ownership and the proposed user workflow. [Acceptance scenarios](openspec/changes/presentabot-foundation/specs/) describe the intended behavior.

Presentations will be independent user folders, with no requirement to use Git or store them inside this repository. Slidev is the selected engine; editable PowerPoint compatibility is a core acceptance concern.
